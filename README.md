# 차원 붕괴

하드 SF 장편 · 1권 연재 중인 초고

세상의 거의 모든 기계가 인공지능 프로메테우스 하나로 생각하는 2060년대. 그 생각을 밤마다 벽에 비춰 보던 연구자 이단 반스는, 아무도 그리지 않은 무늬를 발견한 다음 날 새벽 자기 집 문이 저절로 열리는 것을 본다. 대서양 건너 파리에서는 프리랜서 기자 클레망스 로랑이 잠든 채 숨진 사람들의 마지막 밤을 초 단위로 맞춰 보고 있다.
