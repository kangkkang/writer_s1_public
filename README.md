# 원고

본문 원고를 둔다. 설정의 정본이 아니며, 원고와 정본이 어긋나면 정본(`canon/`, `plot/`)을 따르고 원고를 고친다.

## 파일 규칙

- **권 폴더**: `vol1/`(1막), `vol2/`(2막·허위 유토피아·3막), `vol3/`(4막·5막). 권·막 대응의 정본은 `plot/30-전체지도.md`다.
- **장 번호는 작품 전체의 일련번호다.** 권이 바뀌어도 이어진다(1권 마지막이 `036.md`면 2권 첫 장은 `037.md`). 세 자리로 쓴다. 복선대장(`plot/33-복선대장.md`)과 검토 보고가 장을 하나의 번호로 가리키기 위해서다.
- 장을 쪼개거나 합치면 뒤 번호를 밀지 않고 `012a.md`처럼 접미사를 붙인다. 번호 재정렬은 권 단위 퇴고 때 한 번에 하고, 복선대장의 장 번호를 함께 고친다.

## 장 머리

장 파일 첫머리에 아래 메모를 HTML 주석으로 둔다. 본문 독자에게는 보이지 않는다.

```
<!--
막·비트/블록: 1막 비트 2
시점 인물: 이단
이 장에서 원하는 것 / 방해 / 선택 / 대가 / 변화:
심는 복선: F30
-->
```

장 머리에 시점 인물을 본문으로 표기하지 않는 규칙은 `canon/50-집필규칙.md`를 따른다.
